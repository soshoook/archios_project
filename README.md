## Как измеряется заполненность

Обычная папка не имеет своего "потолка" в байтах, поэтому для измерения
процента заполненности используется отдельный виртуальный диск
ограниченного размера, подключённый к папке. Папка логов и папка бэкапа
обязаны быть на **разных** дисках.

### Linux (.sh)
Заполненность в процентах считается через `df`.

### Windows (.bat)
Виртуальный диск — файл VHD, создаётся и подключается через `diskpart`
(команды `create vdisk` / `attach vdisk` / `create partition primary` /
`format` / `assign letter`). Для теста создаются два VHD: один под `/log`,
другой под `/backup` (по 600 МБ).

**Важно:** подключение VHD на Windows требует прав администратора
(в отличие от Linux, где подключение без root-прав возможно) —
ограничение самой системы Windows.

## Зависимости

 Linux/macOS (.sh)
- `tar` с поддержкой `-z` (gzip) — обычно по умолчанию
- `xz-utils` для LZMA-режима (`sudo apt install xz-utils` на Ubuntu/WSL)

 Windows (.bat)
- gzip: встроенный `tar -czf` — работает без доустановки
- LZMA/XZ: встроенный `tar` не поддерживает `--lzma`; используем 7-Zip
  (`7z.exe`), два шага: `tar -cf` + `7z a -txz`
  Установка: https://www.7-zip.org

## Что считается "старым файлом" и сколько их архивировать

Сортировка по дате изменения файла, от самых старых. Файлы
берутся **по одному**, пока накопленный освобождаемый объём не станет
достаточным, чтобы заполненность опустилась до порога X% (не ниже —
останавливаемся, как только хватает, даже если получилось чуть больше
за счёт последнего файла).

## Обработка ошибок

- Папка не указана или не существует → сообщение об ошибке, скрипт
  завершается без изменений
- X не указан или некорректен → сообщение об ошибке
- Архивация не удалась → исходные файлы **не удаляются**

## Тесты

Минимум 4 автоматических теста (см. `test_cleanup.sh` / `test_cleanup.bat`):
1. Заполнение ниже порога — ничего не меняется
2. Заполнение выше порога — старые файлы архивируются и удаляются
3. Проверка порядка выбора файлов (действительно старые уходят первыми)
4. Другое значение X
5. (бонус) LZMA-режим — отдельный тест
